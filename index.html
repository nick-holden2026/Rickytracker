Safety & glucose log

First two weeks tracking protocol

🚨
Hypoglycaemia protocol (below 70 mg/dL)
  1. Stop training immediately and sit down.
  2. Take 15–20 g fast-acting glucose.
  3. Recheck after 15 minutes.
  4. Do not train through a low.

Before every gym session

Stop training if…

  • Dizziness or feeling faint
  • Unusual weakness
  • Nausea or vomiting
  • Chest pain
  • Severe breathlessness
  • Confusion

Cross-device sync

Optional. Sync between phone and PC using a free Firebase Realtime Database. Sync runs offline-first — your local data is always safe.

Status: Not configured

📖 How to set up Firebase (2 minutes)
  1. Go to console.firebase.google.com and create a free project.
  2. Click Build → Realtime Database → Create Database. Start in test mode.
  3. Project settings → Your apps → </> web icon → register app → copy config.
  4. Paste config below, generate a room code, connect on both devices.
  5. Important: after 30 days Firebase test-mode rules expire. In the Rules tab, replace them with { "rules": { "clay-rooms": { ".read": true, ".write": true } } } to keep sync working.
